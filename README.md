## 🌟 Executive Overview
This project transitions the traditional *"Daily Habit Tracker with Streak Counter"* assignment into a research-oriented behavioral analysis platform. Beyond tracking streaks, it introduces an algorithmic **Habit Synergy Analyzer** that uses **Pandas, NumPy, and Seaborn** to uncover lead-lag behavioral domino effects ($Day_{t} \rightarrow Day_{t+1}$), detecting **Keystone Habits** (e.g., how getting $\ge 7.5$ hours of sleep statistically increases next-day study consistency by 68%).

It features a full **Multi-User Security Gateway** (salted SHA-256 hashing and Gmail SMTP 4-digit OTP password recovery), **Social Gamification** (dual-timeframe leaderboards, Set-theory mutual friend circles, and 7-day 1-on-1 habit duels), and **Dual Persistent Storage (JSON & CSV)** with atomic file protection.
